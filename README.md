# README

## Dependencies

- altair >= 5.5.0
- numpy >= 1.26.0
- pandas >= 2.1.1
- streamlit >= 1.50.0

## Project tree

```console
│   README.md
│   streamlit_app.py
│
├───.streamlit
│       config.toml
│
├───assets
│   └───icons
├───classes
│       gestion.py
│
├───data
└───pages
        analysis.py
        dashboard.py
```

## Launch

To launch the app, run the following command in the terminal :

```console
python -m streamlit run streamlit_app.py
```
